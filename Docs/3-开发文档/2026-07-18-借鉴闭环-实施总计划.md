## Completion evidence

- The template root has exactly one marker, and each instance root has exactly one marker. Unknown or conflicting modes fail hard.
- The A3 mechanical BOM-migration checkpoint proves unchanged decoded content for the original 124 tracked PS1 files and the official scope at that time. Subsequent intentional semantic changes receive separate contract review. Windows PowerShell 5.1 ParseFile ultimately passes for the complete official scope.
- The template contains only the borrowing skeleton. Instantiation copies no sources/items and overwrites no instance data.
- Git, local, and web source cards and the adopt/adapt/reject/defer state contracts have positive and negative examples.
- Before any write, the capture executor rejects roots that are not instances. It implements Git/local/web capture, permission records, atomic promotion, idempotency, and failure without partially completed official artifacts.
- P4t neither connects to the network nor executes external content. It blocks path traversal, invalid closure, and direct application dependencies.
- A temporary instance completes capture, assessment, adaptation, verification, and closure. Older capture references remain stable.
- Fresh P4s, P4t, and P4a-P4t output passes. Every warning has an explicit owner and is not presented as an entirely clean result.
- Existing user changes remain intact. No unauthorized Git or release actions occur.
