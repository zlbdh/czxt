# 借鉴闭环 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 czxt 模板中交付可实例化、可审计、可离线验收的完整借鉴闭环，并恢复其 Windows PowerShell 5.1 验收底座。

**Architecture:** 先以独立 Gate 0 修复根模式识别和 PS5.1 编码契约，再建立单根 `借鉴区/`、来源版本卡与借鉴卡，最后以模块化 P4t 守卫、临时实例和总健康检查收口。来源事实、事项事实、审批事实和实施/验证事实分别保持单一真源。

**Tech Stack:** Windows PowerShell 5.1、Markdown + 受限 YAML frontmatter、Git、SHA-256、现有 check-os façade/plan 体系。

## 全局约束

1. 进入任务时已有 32 个 modified、4 个 untracked 文件；它们属于既有工作，禁止覆盖、删除或用 reset/checkout 恢复。实施前在 workspace 外保存完整字节副本、SHA-256 与 binary patch，收口时逐文件对账。
2. 单源文件（`状态.md`、CHANGELOG、角色边界、交接区、PROP/ADR 索引）只由主会话最后落笔。
3. 每个实现任务先用 `@test-driven-development` 写 RED，再写最小实现；失败时用 `@systematic-debugging`，修改后用 `@test-feedback`。
4. 新脚本按 `@modular-architecture` 拆分；公开 façade 保持短小，helper 单一职责。
5. 修复或踩坑后用 `@dev-memory` 记录可复用结论；完成声明前用 `@verification-before-completion`。
6. 不执行 commit、push、tag、发布或外部分发。计划中的提交信息仅作候选；只有用户另行明确授权时才执行。

## 全局完成证据

- 模板根 marker 唯一，实例根 marker 唯一，未知/冲突模式硬失败。
- A3 机械 BOM 迁移检查点证明原始 124 个跟踪 PS1 及当时正式范围的解码内容不变；随后有意语义修改另走契约审查，最终正式范围 Windows PowerShell 5.1 ParseFile 全通过。
- 模板只含借鉴骨架；实例化不复制来源/事项，不覆盖实例数据。
- Git、本地、网页三类来源卡和 adopt/adapt/reject/defer 状态合同有正反例。
- 来源捕获执行器在任何写入前拒绝非实例根，落实 Git/local/web、权限留痕、原子晋升、幂等与失败无正式半成品。
- P4t 不联网、不执行外部内容，能阻断路径逃逸、非法关闭和业务直接依赖。
- 临时实例完成一次来源捕获、评估、适配、验证关闭；旧 capture 引用保持稳定。
- P4s、P4t、P4a-P4t 的新鲜输出均为通过；任何警告有明确归属且不冒充全绿。
- 现有用户改动仍在；无未经授权的 Git/发布动作。
