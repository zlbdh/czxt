# Borrowing Lifecycle Gate 0 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish reliable template/instance mode markers and restore Windows PowerShell 5.1 parsing for all framework PowerShell scripts without changing script-text semantics.

**Architecture:** `framework-scope.ps1` provides an explicit root-mode API. The template tracks `.czxt-template-root`; instantiation generates `.czxt-project-root`. An independent encoding gate scans framework PS1 files. Mechanical BOM migration changes only the encoding signature, leaving decoded-content hashes unchanged.

**Tech Stack:** Windows PowerShell 5.1 Parser API, UTF-8 BOM, SHA-256, temporary fixtures, and existing P4a/check-os components.

```powershell
function Get-DecodedRows([string[]]$RelativePaths) {

}
```

```powershell
function Assert-SameRows($Expected, $Actual, [string]$Label) {
  $expectedMap = @{}; foreach ($row in @($Expected)) { $expectedMap[$row.Path] = $row }
  $actualMap = @{}; foreach ($row in @($Actual)) { $actualMap[$row.Path] = $row }
  if ($expectedMap.Count -ne $actualMap.Count) { throw "$Label file count changed" }
  foreach ($path in $expectedMap.Keys) {
    if (-not $actualMap.ContainsKey($path)) { throw "$Label missing file: $path" }
    if ($expectedMap[$path].TextSha256 -ne $actualMap[$path].TextSha256 -or
        [int]$expectedMap[$path].CharacterLength -ne [int]$actualMap[$path].CharacterLength) {
      throw "$Label decoded content changed: $path"
    }
  }
}

    [int]$scopeDoc.Count -ne $allFrameworkPs1.Count -or

$scopeActual = @(Get-DecodedRows $allFrameworkPs1)
foreach ($row in @($trackedExpected + $scopeExpected)) {

if (@($scopeExpected.Path | Sort-Object -Unique).Count -ne $scopeExpected.Count) { throw 'Duplicate paths in the official-scope baseline' }
```

```powershell
function Get-CzxtRootMode {
  param([string]$Root)
  $template = Test-Path -LiteralPath (Join-Path $Root '.czxt-template-root') -PathType Leaf
  $project = Test-Path -LiteralPath (Join-Path $Root '.czxt-project-root') -PathType Leaf
  if ($template -and $project) { return 'conflict' }
  if ($template) { return 'template' }
  if ($project) { return 'project' }
  return 'unknown'
}
function Test-IsTemplateRoot {
  param([string]$Root)
  return (Get-CzxtRootMode -Root $Root) -eq 'template'
}
```
