# Borrowing Lifecycle Core Capabilities Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a template-neutral, single-root borrowing area, two card types, permission/state contracts, one execution Skill, and a safe, reusable source-intake workflow.

**Architecture:** `借鉴区/` contains only source-version cards, item cards, and ignored local caches. Rules, Skill, and workflow each own a distinct kind of fact. The Skill is the sole operator-facing entry point and invokes a modular PowerShell capture executor to enforce Git/local/web safety semantics. Add no global database/derived index, hooks, daemon, or automatic-refresh service.

**Tech Stack:** Markdown, restricted YAML frontmatter, PowerShell 5.1, Git, SHA-256, and existing Q1-Q7/L1-L4/A-B-C governance.

> **WinPS invariant:** Before first execution and after every semantic edit, idempotently normalize every new or modified `.ps1` in this plan to UTF-8 BOM, then immediately run `check-winps-encoding.ps1`.
