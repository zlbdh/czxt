# 借鉴闭环 P4t 与收口 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以离线 P4t 契约证明借鉴区结构、来源 capture、事项状态、关闭证据和业务隔离真实成立，并通过临时实例化与 P4a-P4t 总体检收口。

**Architecture:** P4t 公开 façade 只编排 `mode/source/item/isolation` helpers；受限 frontmatter 由内部 parser 读取，不引入 YAML 模块。测试使用临时本地 Git、本地目录和离线网页字节，不联网、不执行来源内容。

**Tech Stack:** Windows PowerShell 5.1、现有 check-os plan/invoke 协议、临时 fixtures、Markdown/regex、Git/SHA-256。

> **WinPS 不变量：** 本计划所有新建或修改的 `.ps1` 在首次执行前及每次语义编辑后都必须幂等归一化为 UTF-8 BOM，并运行真实编码门禁；契约不得因自身编码先于目标断言失败。
