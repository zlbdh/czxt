# Borrowing Lifecycle P4t and Completion Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Use offline P4t contracts to prove borrowing-area structure, source captures, item states, closure evidence, and application isolation, then complete acceptance through temporary instantiation and the overall P4a-P4t health check.

**Architecture:** The public P4t façade only orchestrates `mode/source/item/isolation` helpers. An internal restricted-frontmatter parser avoids a YAML-module dependency. Tests use temporary local Git repositories, local directories, and offline web bytes; they neither connect to the network nor execute source content.

**Tech Stack:** Windows PowerShell 5.1, existing check-os plan/invoke protocol, temporary fixtures, Markdown/regex, and Git/SHA-256.

> **WinPS invariant:** Before first execution and after every semantic edit, idempotently normalize every new or modified `.ps1` in this plan to UTF-8 BOM and run the real encoding gate. Contract encoding must not fail before the target assertions.
