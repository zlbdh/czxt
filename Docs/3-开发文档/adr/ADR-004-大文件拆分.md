# ADR-004 · Split Large Files (Implement PROP-001 Option B3: Split All)

- **Status**: Current
- **Date**: 2026-05-08
- **Decision maker**: zlbdh (approved option B3 in PROP-001)
- **Related**: [PROP-001-2026-05-08-拆分大文件.md](../../../确认改动/已审批/已完成/PROP-001-2026-05-08-拆分大文件.md)

## Context

The 2026-05-08 health check found 5 source files above or near the 9KB mount write limit:

| File | Original size |
|---|---:|
| `{{APP_REPO_DIR}}/src/features/home/Home.jsx` | 13208B |
| `{{APP_REPO_DIR}}/src/shared/components.jsx` | 12137B |
| `{{APP_REPO_DIR}}/src/features/timeline/Timeline.jsx` | 9594B |
| `{{APP_REPO_DIR}}/src/features/health/Health.jsx` | 9133B |
| `{{APP_REPO_DIR}}/src/features/profile/Profile.jsx` | 8579B |

Changes required Python writes because Edit/Write triggered mount truncation; 2 incidents had already lost bytes.

## Decision

**Split all files** under PROP-001 option B3, targeting <6KB per source file (the Edit/Write safe range).

### Split Mapping

#### components.jsx (12137B → 6 files)
- `components.jsx` (core Card/PageHeader/SectionTitle/EmptyState) — 2017B
- `buttons.jsx` (PillButton/PrimaryButton/GhostButton) — 1023B
- `inputs.jsx` (TextInput/TextArea) — 501B
- `stats.jsx` (StatRow/Stat) — 1460B
- `MonthCalendar.jsx` (standalone) — 4075B
- `TaskDetailModal.jsx` (standalone) — 3284B

#### Home.jsx (13208B → 6 files)
- `Home.jsx` (composition, state, handlers, and embedded Training/Habits/Modal) — 6673B
- `HomeStatBar.jsx` (Today's Pulse) — 928B
- `HomeTaskSections.jsx` (task lists for 4 time periods) — 3222B
- `HomeHydration.jsx` (hydration card) — 1542B
- `HomeAIBriefing.jsx` (AI briefing) — 884B
- `HomeChat.jsx` (chat) — 1906B

#### Timeline.jsx (9594B → 2 files)
- `Timeline.jsx` (main view, new entry, AI organization, calendar) — 6279B
- `TimelineList.jsx` (timeline Card) — 3849B

#### Health.jsx (9133B → 2 files)
- `Health.jsx` (main view, weight, training, calendar) — 5955B
- `HealthMeals.jsx` (meals Card) — 4319B

#### Profile.jsx (8579B → 2 files)
- `Profile.jsx` (main view, heatmap, physical profile) — 3684B
- `ProfileExtras.jsx` (4 Cards: AI, backup, device, recent issues) — 5444B

#### Import Updates
Split `from '../../shared/components.jsx'` in 5 feature files into specific imports as needed, with 4–5 import lines per file.

## Consequences

### Benefits
- **All 5 high-risk source files enter the safe range**; the largest is only 6.7KB, well below the 9KB limit.
- Mimi can use Edit on these components again.
- Individual files are much easier to read, generally within one screen.
- Tests can operate at finer, per-component granularity.

### Costs
- File count increases from ~12 to ~26 (13 new files).
- One import line becomes 4–5 lines, adding slight repetition.
- Props pass through 1 additional level; children such as HomeStatBar receive data through props.

### Reconsideration
- **Trigger**: the split makes code harder to find (considered unlikely with clear names).
- **Reversal**: merge manually, approximately 1 hour.
- **Estimated reversal cost**: low.
