# ADR-006 · Navigation Restructuring: Reorder 5 Tabs, Separate Chat, and Move Profile to the Upper Right

- **Status**: Current (implemented after zlbdh approved PROP-003 on 2026-05-09)
- **Date**: 2026-05-09
- **Decision maker**: zlbdh / Mimi
- **Related**: [PROP-003](../../../确认改动/已审批/已完成/PROP-003-2026-05-09-导航重构与聊天独立化.md) / F-NAV-1 / F-CHAT-1

> ⚠️ **Current override notice (2026-06-15)**: The bottom tabs and `/profile` information architecture remain historical evidence for PROP-003. Actual routes are defined in `{{APP_REPO_DIR}}/src/app/AppShell.jsx`. “API key” describes a settings entry, not permission to disclose real secrets or write them into tracked files.

## Context

Physical-device use of the v2.3 development APK exposed two information architecture problems:

1. **Profile occupied 1/5 of the bottom tabs despite infrequent use**. Profile, API key, backup, and heatmap settings are used only a few times a week.
2. **Chat was buried**. Conversation with Mimi is frequent, but its Card sat midway down Home: open Home → scroll → open the Card → type, requiring 4 steps.

Bottom tabs should serve frequent primary functions. Settings should be accessible through a persistent corner control.

Options listed in PROP-003:
- B1: no change → rejected; pain points remain.
- B2: move Profile without adding Chat → rejected; only 4 tabs and Chat remains buried.
- B3: add Chat without moving Profile → rejected; 6 tabs exceed the mobile limit of 5 tabs.
- **B4: move Profile and add Chat**, reordering 5 tabs and adding a permanent upper-right avatar → **accepted**.

## Decision

### Information Architecture

| Position | Before | After |
|---|---|---|
| Tab 1 | Today (/) | Today (/) |
| Tab 2 | Health (/health) | Health (/health) |
| Tab 3 | Accounting (/accounting) | **Chat (/chat)** ★ |
| Tab 4 | Timeline (/timeline) | Accounting (/accounting) |
| Tab 5 | Profile (/profile) | Timeline (/timeline) |
| Upper right | — | **Permanent 30×30 avatar → /profile** ★ |

Chat occupies position 3, the center, matching the principle of placing a frequent function in the natural thumb zone.

### Code

1. **Create `{{APP_REPO_DIR}}/src/features/chat/Chat.jsx`**, a full-screen chat page.
   - Move all interactions from `{{APP_REPO_DIR}}/src/features/home/HomeChat.jsx`: message list, input, send button, Enter submission, and loading dots.
   - Add automatic scrolling to the bottom after each new message using scrollTo.
   - Attach the F-203 archive drawer here; open it through the SectionTitle “View History” action.
   - Reuse the `addChatMessage` action, `chatArchive.js` pure functions, and `ChatHistoryDrawer.jsx`.

2. **Change `{{APP_REPO_DIR}}/src/app/AppShell.jsx`**.
   - Reorder the 5 tabs: Home / Health / **Chat** / Accounting / Timeline.
   - Keep the Profile route **outside the tabs array**, hidden from bottom navigation.
   - Give each of the 5 ErrorBoundary components a key, including `key="chat"`.
   - `import ChatPage from '../features/chat/Chat.jsx'`

3. **Change `PageHeader` in `{{APP_REPO_DIR}}/src/shared/components.jsx`**.
   - Upgrade `action` to the clearer `rightAction` prop.
   - **Default**: when `rightAction` is omitted, render a 30×30 circular User icon button with `Link to="/profile"`.
   - Border: 1px solid `inkSoft` (#3a3128).
   - **`rightAction={null}`** explicitly disables rendering; Profile uses it to avoid a self-link.

4. **Change `{{APP_REPO_DIR}}/src/features/home/Home.jsx`**.
   - Remove `import HomeChat from './HomeChat.jsx';`.
   - Remove `<HomeChat ... />` JSX.
   - Remove `chatText / chatLoading / sendChat / recentChat` state and functions.
   - Remove the unused `callAI` import.
   - Add the upper-right avatar to Home's custom hero header with its 3.2rem weekday text; use the same helper component and style as PageHeader.

5. **Delete `{{APP_REPO_DIR}}/src/features/home/HomeChat.jsx`**, which has no remaining references; ADR-006 retains no unused file.

### Visual Specification (Added to `rules/visual/视觉设计规范.md`)

**Upper-right entry control**
- Position: right side of each PageHeader, aligned to the title baseline.
- Shape: 30×30 circle (`rounded-full`).
- Border: 1px solid `inkSoft` (#3a3128).
- Content: centered `User` icon from lucide-react, 14×14, `color: ink`.
- Interaction: `<Link to="/profile">`.
- Exception: Profile passes `rightAction={null}` to hide it.

## Consequences

### Benefits
- Chat access decreases from 4 steps to 1 tab press.
- Information architecture matches usage frequency: frequent functions below, settings above.
- F-203's archive drawer belongs naturally on the Chat page rather than a Home Card.
- Removing HomeChat reduces Home.jsx's size.

### Costs
- PageHeader's `action` → `rightAction` change affects 5 feature headers, with backward compatibility: `action` remains accepted at lower precedence than `rightAction`.
- Users accustomed to Profile at the bottom right need 1–2 uses to adjust.
- HomeChat.jsx deletion is recorded as irreversible, though Git history retains it.

### Reconsideration
- **Reversal**: move Chat.jsx content back into HomeChat.jsx and restore AppShell's 5 tabs and ErrorBoundary configuration.
- **Estimated reversal cost**: 1.5h, including 4 documentation changes.
- **No data loss**: chatMessages remains untouched.
