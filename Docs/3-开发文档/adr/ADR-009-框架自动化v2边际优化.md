## Context

ADR-008 (PROP-005) moved the rules from semiautomatic to 90% fully automatic. Health check v20 found 6 **incremental improvements** toward 95%: real risks, though not blocking.

1. 状态.md lacked expiration detection, allowing stale cache use.
2. State-inference suggestions lacked tracking, repeating dismissed recommendations.
3. DoD kept growing, encouraging selective omission.
4. Session startup depended on AI initiative without a mandatory trigger.

Items #5 and #6, aging in-progress PROP warnings and proactive placeholder monitoring, were lower priority and deferred to RETRO-003.

## Decision

Make 4 incremental improvements:

### P1 — Detect Stale 状态.md
Upgrade inference 5: compare 状态.md mtime with the latest code-change mtime. A gap ≥1 day marks it 🟡 stale. AI **must not use stale 状态.md data directly**; proactively rerun inferences 1–4 to reconcile.

### P2 — Track Suggestions and Decisions
Add a recent suggestions/user decisions table to 状态.md and an anti-repetition section to the state-inference skill. Do not repeat dismissed suggestions for 7 days.

### P3 — Reorganize DoD
Add a “⭐ 5 required core checks” summary to L3/L4 DoD in 实施循环.md:
- Code / tests / PRD / PROP closure / run both reconciliation skills.
Mark remaining items as extensions, applied when needed.

### P4 — Mandatory Session Startup Trigger
Add two prominent reminders:
- A 🚨 first-action sequence of 4 steps at the top of agent/INDEX.md.
- The same section in root README.md, visible on entry.
