## Context

During a 2026-05-11 transition from Claude Code implementation to Codex testing, zlbdh explained that the problem was the flow of status and information, not manual copying and pasting.

The **actual problem** was that the existing 3-section package—completed work, next steps, warnings—was too abstract. Recipients spent 5–10 minutes inspecting git status, wc -c, and history before continuing.

Examples:
- After Claude Code finishes code, Codex does not know changed files, sizes, completed tests, or remaining tests.
- After Codex finishes tests, Claude Code does not know passes, failures, or returned code changes.

## Decision

Upgrade the synchronization package to a **structured 6-section handoff card**.

### 6 Required Sections
1. **Time and role transition**: from A to B.
2. **File changes**: `+ M -` markers, byte sizes, warnings at ≥6500B.
3. **Test status table**: environment capabilities, executed tests, and results.
4. **Recipient checklist**: specific actions; “test it” is insufficient.
5. **Warnings**: large files, TODOs, risks.
6. **Follow-up Q&A**: bidirectional questions when work returns for revision.

### Two Defenses
1. **Latest handoff at the top of root `状态.md`**: complete 6-section cross-session cache.
2. **Compact handoff text**: 6 shortened sections for user copy/paste.

## Backward Compatibility

The old 3 sections are **fully covered by the new 6**:
- Completed work ≈ ① + ②.
- Next steps ≈ ④.
- Warnings ≈ ⑤.
- New: ③ test status and ⑥ follow-up Q&A.

When reading the old format, inference 5 recommends upgrading on the next implementation. Do not require rewriting historical records.

## Consequences

### Benefits
- ✅ Handoff time decreases from 5–10 minutes to ≤1 minute.
- ✅ Claude Code / Codex / Cowork share one format.
- ✅ Section ② embeds large-file warnings.
- ✅ Capability-specific test evidence exposes claims of tests that were not run.

### Costs
- ❌ 状态.md's top section grows by approximately 1.5KB.
- ❌ Writing a card takes 30 seconds more than 3 sections, while saving the recipient 5–10 minutes.
