# Technology Stack

> The template root does not prescribe the application's technology stack. After initialization, fill in the project instance's verified facts. Leave unsupported fields as `[fill in]` or mark them as pending verification.

## Project instance source of truth

Record sources in descending order of authority:

1. Manifests, lockfiles, toolchain configuration, and runtime version files.
2. CI/build scripts and output from actual command runs.
3. Approved ADRs.
4. The summary in this document.

Do not enter versions from memory. Record declared version ranges separately from actual locked versions.
