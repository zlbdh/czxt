## PM correction 54 case study

### Trigger

The handoff `2026-05-20-1430-PROP-025-PRD-起稿-Cowork到ClaudeCode.md` contradicted itself between section ⑤ steps 7/8 and AC2:

- Step 7 used extensionless exports such as `export * from './schema'` in index.js.
- Step 8 removed database.js, relying on Vite to resolve database/index.js.
- AC2 required zero caller changes.
- Verification showed four callers used the explicit `../shared/database.js` extension.
- Vite/Vitest would not strip .js and reinterpret that path as a directory; deletion would break all four imports.

### Root cause

PM assumed directory-resolution behavior without searching the actual import style. This repeated BR's model-identity assumption, BP's 401 misclassification, and F-DIARY-1's wrong UI proposals: verify before inferring.

### Correct decision

Claude Code retained database.js as a 655 B wrapper containing `export * from './database/index.js'`; PM accepted it.

This preserved all callers, satisfied AC2 more faithfully than step 8, reduced the largest module to 4989 B with 11,395 B of room below 16 KB, and left the tiny wrapper insensitive to future caller growth while schema modules expand separately.
