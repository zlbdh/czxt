## 2. What worked

1. **⭐ Hooks immediately demonstrated value.** The release gate exposed a false green caused by npm.ps1, and the Stop chat-summary hook rejected its own author's response for missing the ①–⑦ handoff. Catching real defects immediately after introduction supported the design.
2. **Pointer drift was traced to its cause.** A subagent incorrectly reported v3.6.5/Sprint-5 because current-document anchors lagged the authoritative {{APP_REPO_DIR}}/package.json. Synchronizing all pointers and adding P4h addressed both the stale values and future recurrence.
3. **Two B-lite trials had zero boundary violations.** R1 covered 26 files through three workers. R2 covered 35 files, recorded as 33 worker + two single-writer items. Exact changed-versus-assigned counts matched and no-parallel sentinels were untouched. The AC2 dispatch card's disjoint-set field worked twice.
4. **State-history archival conserved bytes.** Older records moved into `状态-archive/`, reducing 494KB to 158KB, −68%, with byte-level proof of zero loss. ADR-033's truncation lesson became a prerequisite to verify conservation before archival.
5. **Negative tests became part of the process.** P4h was tested by changing README to Sprint-99 and observing exit 1. The release gate's complete device run, required by ADR-033 after framework-tool changes, caught the npm.ps1 problem. Prove that a guard detects a defect before trusting it.

## 3. Problems and inefficiencies

1. 🔴 **B-lite barrier waiting in R1.** Worker duration spread was **5.5×**: files were divided 11/9/6, but skills took more effort, with B at 305s versus A at 79s and C at 55s. Better balancing reduced R2's spread to **1.5×**. Balance by estimated work rather than file count, or use a pipeline. Candidate **DU**, recorded in RETRO-021, gained a second data point through R1 → R2.
2. 🐛 **npm.ps1 nearly blocked all pushes incorrectly.** PowerShell's illustrative invocation `& npm <subcommand>` resolved to npm.ps1 and passed incorrect arguments, leaving npm with “pm” or an unknown-command error. The full device run caught it. `cmd /c "npm ..."` resolved the issue. Proposed practice: invoke npm through `cmd /c` in framework tools to avoid PowerShell shim parsing.
3. 🟡 **Estimated PM timestamps were systematically early.** Manually entered tracking times were hours below measured time; `check-pm-tracking` caught them. Use measured `Get-Date` values instead of estimates. Candidate **DW**, recorded here as already noted in RETRO-021.
4. 🟡 **Codex had automation while Claude relied on discipline.** Previously only `.codex/hooks.json` existed, leaving Claude's SessionStart/UserPromptSubmit/Stop behavior manual. This batch added the matching `.claude/settings.json`. Cross-tool framework automation needs comparable safeguards on both sides.
5. 🟡 **Current-pointer documents drift without anchor guards.** README/AGENTS naturally lag the source of truth. P4g's list checks could not protect values such as current version/Sprint; P4h filled that gap. Any active document copying authoritative values needs an automated consistency assertion.
