# Quick Reference: ADR-022 Decision 5 — Path Ownership

> Spend 30 seconds checking before handoff / PROP / chat to prevent repeats of PM self-corrections #41/#42.

## Rule: classify by file path, not task type

| Category | Paths | Responsible role |
|---|---|---|
| **Framework maintenance** | `操作系统/`, `能力资产/`, project root AGENTS.md / 状态.md / README.md, `Docs/`, `确认改动/`, `交接区/` | **Project PM switches to Operating System PM** |
| **Private PM workspace** | `PM工作区/<对应PM>/` | **The corresponding PM governs it; Project PM may coordinate but cannot reorganize across boundaries** |
| **Application code** | All .js / .jsx under `{{APP_REPO_DIR}}/src/`, including refactors and features | **Development PM “Implementer”** |
| **Test code** | `{{APP_REPO_DIR}}/src/__tests__/*.test.js` | **Development PM “Implementer” writes; Test PM “Quality Gate” sets strategy** |
| **Completion verification** | Version bump, APK build, vitest, physical-device smoke, git commit/push | **Test and Release PM “Closer”** |

## Nine internal PM roles: PROP-020 path D + v4.0

Project PM “Mimi” coordinates eight roles:

| Role | Responsibility |
|---|---|
| Operating System PM “Framework Steward” | `操作系统/`, `能力资产/`, and other framework paths |
| Product PM “Requirements Analyst” | `Docs/1-需求文档/` |
| Technical PM “Fix Strategist” | Read-only diagnosis |
| Test PM “Quality Gate” | Test strategy |
| Operations PM “Operations Mimi” | `PM工作区/运营PM-运营咪咪/` |
| Development PM “Implementer” | `{{APP_REPO_DIR}}/src/` |
| Test and Release PM “Closer” | Completion verification |
| Knowledge PM “Curator” | Cross-PM knowledge and meta-rules |

## Common misrouting examples

- ❌ **Self-correction #41:** PM directly used Write on `{{APP_REPO_DIR}}/src/anomalyDetector.js` without changing roles. Run decision-checkpoint, then switch to Development PM “Implementer” or write a handoff.
- ❌ **Self-correction #42:** treating the task as “framework governance” incorrectly bypassed the path allowlist. **Check paths, not task type.**

## Three questions before switching roles

1. Q1: Which role owns this work?
2. Q2: Does its path allowlist permit it? Search [role boundaries](../../../操作系统/01_架构/角色边界.md).
3. Q3: Outside the boundary? Write a handoff or switch roles.
