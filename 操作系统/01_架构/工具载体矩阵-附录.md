## Migration cost: 2026-05-22 snapshot

> This section explores candidate routes. Current execution boundaries come from the main document and role boundaries.

### Low-cost changes: ready in v4.0

- ✅ Cowork → Claude Desktop / Claude.ai for lead decisions: no migration; the entire framework is in the project directory.
- ✅ Claude Code → Cursor Agent / Cline for implementation: the new tool only needs to support editing `{{APP_REPO_DIR}}/src/`.
- ✅ Codex → GitHub Actions / Jenkins for verification and release: configure the six ADR-016 conditions.

### Medium-cost changes: pending v4.0 SDK integration

- 🟡 Multiple forms of automated hooks, such as existing Codex + Claude hooks and Cursor's different implementation.
- 🟡 Skills SDK integration: Anthropic Skills or equivalents in other tools.

### High-cost changes: v5.0+ exploration

- 🔴 Mem0 / Letta SDK integration for memory governance.
- 🔴 Entity-relationship graph memory.
