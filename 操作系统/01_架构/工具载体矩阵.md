# Tool Matrix · Separate PM Responsibilities from Tools

> ⭐ **Current tool mapping / v4.0 abstraction layer** (task #104.4 / 2026-05-22 / PM self-correction #64, issue CT).
> **Core principle**: PM roles are stable collaboration responsibilities; tools are replaceable implementations.
> **Governance PMs**: Operating System PM “Framework Steward” and Project PM “Mimi”.
> See the [appendix](工具载体矩阵-附录.md) for candidate comparisons, migration costs, upgrade paths, and the cross-project vision.

---

## 1. Core principle (PM self-correction #64)

### ❌ Incorrect approach

Using tool names as PM role names:
- ❌ Cowork PM.
- ❌ Claude Code PM.
- ❌ Codex PM.
- ❌ Cross-tool dispatch (PM self-correction #66).

### ✅ Correct approach

Name PM roles by their responsibilities; treat tools as replaceable implementations:
- ✅ Project PM “Mimi” + five decision PMs + Knowledge PM + Development PM “Implementer” + Test and Release PM “Closer”.
- ✅ Cross-PM dispatch, rather than “cross-tool” dispatch.

## 4. Cross-PM dispatch protocol (PM self-correction #66)

Dispatch is always **between PM roles**, regardless of the tools those PMs use.

| Protocol | Purpose | Tool independence |
|---|---|---|
| **Handoff card sections ①–⑥; section ⑦ recommended for framework work** | Standard format for cross-PM transitions | ✅ Plain Markdown, readable and writable by any tool. |
| **Short chat handoff sections ①–⑦** | Standard implementation-completion report | ✅ Plain Markdown. |
| **Record in `状态.md`** | Timestamped PM transition row | ✅ Plain Markdown. |
| **PROP / ADR / RETRO** | Decision record series | ✅ Plain Markdown. |
| **Decision-checkpoint Q1–Q7** | Workflow decisions, including agent-instantiation decisions | ✅ Workflow abstraction. |
| **Meta-rule pool** | Current permanent and candidate counts come from `元规则池.md` | ✅ Tool-independent rules shared across PMs. |

⭐ **Key design principle**: Cross-PM protocols use **plain Markdown and are tool-independent**, allowing future tool changes, such as Cowork → Cursor, without protocol migration.
