## One sentence

Explain the proposal in one sentence. If that is difficult, the idea probably needs more thought.

## Background and motivation

What prompted this? Whose problem does it solve?

- A specific triggering moment.
- Current problems or missing capabilities.

## Proposed approach

Describe the direction without implementation detail:

- What changes in the interface?
- Are new or changed data fields needed?
- Which existing features overlap or conflict?

For a bug, provide reproduction steps, expected behavior, and actual behavior.

## Estimated impact and cost

- Effort: S / M / L.
- Affected files: approximately N.
- Risks, if any.
- Schema change: Yes / No. If yes, the level is at least L4.

## Alternatives, if any

List and compare options A, B, and C before choosing one.

## Likely reasons for rejection

Write one or two sentences beginning, "If zlbdh rejects this, the most likely reason is..." This helps zlbdh decide and helps Mimi evaluate whether the idea is necessary.
