# PROP-004 · 完整借鉴闭环

- **状态**：已审批 · 已完成（2026-07-19 实施完毕；2026-07-22 终审加固，对应 ADR-039 现行）
- **日期**：2026-07-18
- **责任角色**：项目 PM 编排与验收；操作系统 PM 治理框架；目标决策 PM 评估；按目标路径白名单选既有责任 PM / 实施载体落地
- **改动等级**：L4
- **行为分类**：B 类（受约束的本地实施与验证；`content-deleted` 后不可逆，所有权无法证明的残留必须保留；Git 与发布动作仍需另行授权）

## 授权依据

用户在同一任务链中连续提出并确认：

1. “借鉴用户指定的另一套操作系统；添加‘借鉴’功能”；
2. “A；先生成方案”；
3. “检查方案，给我最终方案”；
4. “你自己设置目标持续推动落地”。

据此，本 PROP 已获方案 A 的本地持续实施授权，不再停留于待审批状态。授权不包含 `commit`、`push`、`tag`、`release`、发布或任何外部分发；如后续需要这些动作，仍须按 ADR-016 另取明确授权，由测试发布 PM 单点执行。

## 目标

把一次性的跨项目反向学习升级为可重复、可审计、可实例化的完整借鉴能力：冻结来源版本，形成候选与采纳决策，把获准内容本地化到当前项目，以验证证据关闭事项，并保留拒绝、延后和历史版本。

本次改动属于操作系统模板框架能力建设：

- 模板只携带中立骨架、规则和工具，不携带具体历史来源卡、事项卡或来源源码；
- 实例中的业务代码不得直接依赖 `借鉴区/`、来源缓存或外部内容；
- 采纳内容必须复制或适配到既有目标路径，并由该路径的责任角色与现有验证体系负责。

## 实施阶段

### A. Gate 0（已完成并有证据）

已冻结任务前脏工作区，建立 Windows PowerShell 5.1 编码/解析门禁，完成正式范围 UTF-8 BOM 机械迁移，并以显式模板/实例标记取代启发式模式识别。A1 与 A3 的工作区外证据保存原始字节、哈希、清单与迁移对账结果，既有改动不得被覆盖、删除或用 Git 恢复命令修饰。

### B. 核心能力（已完成）

建立单根 `借鉴区/`、来源版本卡与借鉴卡，补齐权限、安全、角色路由、唯一 Skill、受测试机器 façade 和完整工作流；模板实例化只复制空骨架，不覆盖实例数据。实例化器采用 no-overwrite 两段移动、物理最终路径绑定和输出 manifest；单文件事务失败时保留无法证明所有权的可审计残留，不承诺整棵项目的全局原子回滚。

### C. P4t 与收口（已完成）

已以契约测试实现只读、离线的 P4t 一致性守卫，完成临时实例 dogfood、业务零依赖检查、P4s/P4t 与双端总健康检查；同源 fingerprint 不变时 REUSED，改变时才新增 capture，关闭事项旧引用与 seal 保持不变。隔离扫描以 8 MiB 为全量/64 KiB 前缀观测边界，并让三轮实际读取共用一次 fail-closed 资源预算。

关闭事务只在 ownership 可证明且未进入 `content-deleted` 时恢复原活动卡；`seal-ownership-unproven` 保留当前正式卡与 staging，`content-deleted` 不可逆完成点后不回滚正式卡，所有后来对象与失败残留都不得被猜测性覆盖或删除。

## 固定验收顺序

1. Gate 0：模式契约、编码契约和真实 Windows PowerShell 5.1 门禁；
2. 核心骨架、文档、捕获执行器和治理契约；
3. P4t 正反例契约与临时实例完整借鉴事项；
4. P4s、P4t 专项；
5. P4a-P4t 总体检；
6. 与任务前脏工作区证据逐文件对账，最后才允许治理收口。

本次必需检查已全部通过，软警告已归属；因此于 2026-07-19 按 ADR-039 收档到“已审批 · 已完成”。

## 边界与风险控制

- 不执行、构建、安装、自动刷新或向上游写入来源内容；验收不联网。
- 不记录凭据、私有访问参数或本机绝对路径到模板当前真值。
- 来源 capture 身份不可变；fingerprint 不变返回 REUSED，改变才创建新 capture，旧事项不漂移。
- 已有脏工作区属于既有工作；A1/A3 外部证据作为保护基线，无法对账即停止。
- 不删除历史 ADR/PROP 正文；现行演进通过 ADR-039 与顶部覆盖指针表达。
