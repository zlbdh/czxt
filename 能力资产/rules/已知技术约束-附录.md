# Known Technical Constraints: Appendix

Use the [main reference](已知技术约束.md) for frequent lookups.

## 1. Mount write truncation risk

Historical behavior: Claude's `Write` / `Edit` tools sometimes truncated mount-filesystem files at roughly 9105 bytes. The tools reported success, but the tail was incomplete. On 2026-05-08, further checks confirmed that even a small edit to a file near 8KB could remove its tail.

Historical examples:

- `Sprint-1需求清单.md` was about 9KB; after Edit, only 8250 bytes remained and the ending was damaged.
- Repeated Edit operations on `需求历史.md` lost the entire v1.x section and the decision log section.

Historical recommendations, since refined by the current P4b tiers:

- The earlier coarse tiers were: edit directly below 6KB; prefer scripted writes or splitting at 6–9KB; prefer splitting above 9KB.
- Current authority: the [main reference](已知技术约束.md) and `check-operating-system.ps1` P4b, with 6000 / 6500 / 8000B tiers.
- For critical judgments, trust the Windows host PS1 check plus Read verification. Use bash `wc -c` only to identify candidates.

Historical verification example from the old environment:

```bash
wc -c target_file
tail -c 200 target_file | xxd | tail -3
python3 -c "open('target_file','rb').read().decode('utf-8', errors='strict'); print('OK')"
```

## 2–4. Sandbox, dependencies, and temporary directories

- The sandbox cannot directly build an APK: `dl.google.com`, `maven.google.com`, and `services.gradle.org` may be unreachable; sudo is unavailable for installing JDK 17; disk space may also be insufficient.
- The first sandbox `npm install` is slow and may be killed by a 45-second timeout. Use `npm install --no-audit --no-fund --silent` and retry failures once or twice.
- `/tmp` is not persistent. Directories such as `/tmp/mimi-test` and `/tmp/mimi-build` cannot serve as long-term state.

## 5–7. Android, JDK, and dependency platforms

- The Capacitor 6 Gradle plugin requires JDK 17 bytecode. JDK 21+ may produce `Unsupported class file major version 65`.
- Without `ANDROID_HOME`, the build reports `SDK location not found`.

```cmd
ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk
```

Alternatively, write `android/local.properties`:

```properties
sdk.dir=C\:\\Users\\zlbdh\\AppData\\Local\\Android\\Sdk
```

Windows `node_modules` includes Windows binaries such as `@rolldown/binding-win32-x64`. A Linux sandbox must install its own Linux dependencies.

## 8–10. Storage, CSS, and quotas

- Old v1 code used the Claude Artifact-specific `window.storage.get/set/delete`. The current `src/storage-shim.js` loads before `main.jsx` and maps it to localStorage. New code must use Dexie / IndexedDB directly instead of `window.storage`.
- CSS font `@import` statements must precede `@tailwind base`; otherwise, PostCSS warns and the imports do not work.
- localStorage provides about 5MB. Put chat history, backups, and other large datasets in IndexedDB. Use localStorage only for small configuration values such as API keys, budgets, and settings flags.

## 11. Misaligned arguments in the `npm.ps1` shim

On the local machine, `npm` may resolve to `D:\Program Files\nodejs\npm.ps1`. In PowerShell, `& npm test` can misalign the arguments: npm receives `"pm"` and reports `Unknown command: "pm"`.

Defenses:

- Use `cmd /c "npm <subcommand>"` in scripts.
- Or call `& npm.cmd <subcommand>` directly.

The release gate hook first encountered this on 2026-06-14. The full host run required by ADR-033 caught it, and it was fixed.

## 12. Premature termination with PS5.1 `2>&1` and EAP=Stop

In Windows PowerShell 5.1, `& <native-command> ... 2>&1` merges stderr into the output. If the script sets `$ErrorActionPreference="Stop"`, any line written to stderr may be wrapped as a `NativeCommandError` and terminate the script early.

Symptom: the native command actually exits with code 0, but the script reports failure.

Defense: temporarily lower EAP while capturing output, and judge success only by `$LASTEXITCODE`. If only the exit status is needed, stderr does not need to be merged.

This appeared during the first real `hooks-smoke.ps1` run on 2026-06-14: a harmless vite deprecation warning reached stderr and caused a false smoke failure. The hooks smoke support layer now includes regression coverage.
