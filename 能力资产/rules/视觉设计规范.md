# Visual Design Rules: Mimi's Literary Style

This document defines the visual identity of {{PROJECT_NAME}}. Follow it for every UI change.

## Theme: Mimi's literary style

Use a warm, literary presentation rather than a brightly colored children's app or a cold engineering report.

**Ivory backgrounds, large serif type, dark contrasting cards, and generous whitespace create the intended character.**

## Colors

| Token | Value | Use |
|---|---|---|
| bg | `#f5f1ea` | Main background: ivory |
| card | `#ffffff` | Standard card background: white |
| cardSoft | `#fdfaf3` | Secondary cards and nested blocks |
| ink | `#2a2520` | Primary text and dark card background |
| inkSoft | `#3a3128` | First lighter shade on inverted cards |
| muted | `#9b9388` | Secondary text |
| faint | `#cbc3b6` | Lowest-emphasis text and placeholders |
| line | `#ece5d8` | Borders and separators |
| accent | `#8a5a3c` | Brown accent for buttons and progress bars |
| green | `#5f7a51` | Completion and success |
| red | `#b56b5f` | Danger and over-budget states |
| blue | `#5b7691` | Water intake and information |
| amber | `#c98a3f` | Notices |

## Fonts

```text
English and numeric headings: Fraunces (serif)
English and numeric body text: Plus Jakarta Sans (sans serif)
CJK heading fallback: Noto Serif SC / Songti SC (serif)
CJK body fallback: Noto Sans SC / PingFang SC (sans serif)
```

Classes:

- `.ff-display`: serif, for headings.
- Default: sans serif.

## Type scale

| Use | Size | Weight | Line height |
|---|---|---|---|
| Hero, such as Monday | 3.2rem | 500 | 1 |
| Page heading | 2.85rem | 500 | 1 |
| Section heading | 1.4rem | 500 | tight |
| Statistic | 1.55rem | 500 | none |
| Large number, such as water intake | 2.6rem | 500 | none |
| Body | 14px / 0.875rem | 400 | relaxed |
| Secondary body | 12px | 400 | relaxed |
| Eyebrow label | 11px | 400 | normal |
| Smallest caption | 9–10px | 400 | normal |

## Letter spacing

| Element | Letter spacing |
|---|---|
| Uppercase English eyebrow | 0.28em |
| Uppercase English section label | 0.2em |
| Other uppercase English text | 0.18em |
| CJK text | 0, unchanged |

## Corners

| Element | Radius |
|---|---|
| Large card | rounded-3xl (24px) |
| Medium card or nested block | rounded-2xl (16px) |
| Button or pill | rounded-full |
| Input | rounded-2xl |
| Small icon button | rounded-md |

## Spacing

- Between cards: `space-y-4` (16px).
- Between sections: `space-y-5` (20px).
- Card padding: `p-5` (20px).
- Between list items: `space-y-2` (8px).

## Three card styles

### 1. Standard card: `<Card>`

- Background: white.
- Border: 1px ece5d8.
- Radius: 3xl.
- Use: 99% of information blocks.

### 2. Dark contrasting card: `<Card dark>`

- Background: ink.
- Text: bg ivory.
- Radius: 3xl.
- Use one per page for the most important statistic or hero information. Never use more than two.

### 3. Soft card: cardSoft background

- A secondary block nested inside a standard card.
- Example: an individual statistic's background.

## Entrance animation

- Page entrance: fadein (0.45s).
- Staggered cards: fadein-1 / fadein-2 / ... / fadein-5, with 60ms added per step.
- Completed check-in: pop, a 0.32s scale animation.
- Dialog: slideup, 0.32s from the bottom.

## Eyebrow pattern

Place a small English eyebrow above each title:

```text
TODAY · MAY 7      Eyebrow: 11px, uppercase, 0.28em
Thursday          Large heading: 2.85rem, ff-display
```

The source specification calls these the five page eyebrows and includes the following entries:

- Today: `today`.
- Health: `health`.
- Chat: `chat`, added 2026-05-09 under PROP-003.
- Accounting: `ledger`.
- Timeline: `moments`.
- Profile: `profile`, accessed through the upper-right avatar.

## Upper-right profile entry: PROP-003 / ADR-006, 2026-05-09

Every page's `PageHeader` renders a persistent avatar button on the right by default. Clicking it navigates to `/profile`.

| Property | Value |
|---|---|
| Position | Right side of PageHeader, aligned with the top of the title block: `mt-2 shrink-0` |
| Shape | 30×30 circle: `rounded-full` and `width: 30, height: 30` |
| Border | 1px solid `inkSoft`, `#3a3128` |
| Background | bg, `#f5f1ea` |
| Content | Centered lucide-react `User` icon, 14×14 (`w-3.5 h-3.5`), colored `ink` |
| Navigation | `<Link to="/profile">` |
| Exception | The Profile page passes `rightAction={null}` to avoid linking to itself |

Implementation: `{{APP_REPO_DIR}}/src/shared/components.jsx`, in `ProfileAvatarLink` and the `PageHeader` defaults.

Constraints:

- Keep clear of the status bar with both `pt-2` and `mt-2`.
- Align approximately with the top of the 2.85rem `<h1>`.
- Home uses a 3.2rem hero heading; retain the same `ProfileAvatarLink` for consistency.

## Prohibited patterns

- Large blocks of clashing colors, gradients, or neon.
- Cartoon icons or emoji everywhere. Use emoji sparingly, at most one per line.
- Stilted copy such as “Quickly record one of your financial transactions.” Use “Add transaction.”
- Heavy shadows or three-dimensional effects.
- Grids with more than five columns.
- Making every Card dark, which removes contrast.
