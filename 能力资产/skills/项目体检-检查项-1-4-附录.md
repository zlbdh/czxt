# Project Health Check — Checks 1–4 Appendix

> Frequently used decision rules: [Checks 1–4](项目体检-检查项.md).

## Check 1: Source-file size commands

> This occasional Bash scan identifies candidates only. P4b in `check-operating-system.ps1` is authoritative and excludes `状态-archive`, `CHANGELOG-2026*`, `历史归档/`, and `agent-*-历史.md`.

```bash
cd "<project root>"

# Scope: only {{APP_REPO_DIR}}/src, 操作系统/, and 能力资产/.
find {{APP_REPO_DIR}}/src 操作系统 能力资产 -type f \( -name '*.jsx' -o -name '*.js' -o -name '*.ts' -o -name '*.tsx' -o -name '*.md' -o -name '*.ps1' -o -name '*.json' \) \
  | grep -Ev '状态-archive|CHANGELOG-2026|历史归档|agent-(INDEX|README)-历史\.md' \
  | xargs -r wc -c \
  | awk '$1>=6000 && $2!="total" {print $1" "$2}' | sort -rn
```

Use two sources for important decisions:

1. Run Bash `wc -c` to identify candidates.
2. Verify files at or above 6500B (Cowork) or 8KB (Claude Code/Codex) with Read.
3. If Bash and Read disagree, trust Read.

Historical split: the six files at or above 6500B identified by PROP-008 / ADR-011 on 2026-05-11 have been split; see [ADR-011](../../Docs/3-开发文档/adr/ADR-011-6500B文件拆分.md). Tool-specific thresholds remain in effect after PROP-013.

## Check 4: Legacy-path residue commands

> P4j/P4k in `check-operating-system.ps1` are authoritative. The following is a manual diagnostic template. Historical archives, `agent-*-历史.md`, current relative links under `能力资产/rules/`, and this file's own explanations are not residue.

```bash
cd "<project root>"

grep -aPn "agent/|Agent/|(?<!能力资产/)rules/" \
  README.md 操作系统 能力资产 Docs/3-开发文档/项目结构.md Docs/3-开发文档/adr/README.md \
  Docs/7-复盘/README.md Docs/7-复盘/_模板.md \
  确认改动/README.md 确认改动/_模板.md 2>/dev/null \
  | grep -vE "历史归档|状态-archive|CHANGELOG-2026|agent-(INDEX|README)-历史\.md|项目体检-检查项-1-4-附录\.md" \
  | grep -v "Agent/ 整合到 rules/\|agents/skills/workflows/rules" \
  | grep -v "│   ├── rules" \
  | grep -vE ":[0-9]+:\| ADR-[0-9]+ \|"
```

Decision template:

```bash
out=$(...the grep pipeline above...)
[ -z "$out" ] && echo "✅ Passed" || printf '🔴 Residue:\n%s\n' "$out"
```

Historical records may retain `rules/...`, `Agent/agents/`, `Agent/skills/`, and `Agent/workflows/`. These are migration mappings and context from that time, not current sources of truth. Current capability assets' own relative `rules/` links are also not legacy-path residue.
