## P4c Bash fallback: rough estimate

> This fallback is for older environments and is not equivalent to PS1 P4c. The authoritative P4c excludes `历史归档`, `状态-archive`, and `CHANGELOG-2026`, and counts other documents containing the filename.

```bash
# Change to the current project root: {{PROJECT_ROOT}} on Windows/Codex,
# or /sessions/<sandbox>/mnt/{{PROJECT_NAME}} on Cowork.
cd "<project root>"

for f in $(find 操作系统 能力资产 -name '*.md' -type f | grep -Ev '历史归档|状态-archive|CHANGELOG-2026'); do
  name=$(basename "$f")
  count=$(grep -l "$name" \
    $(find 操作系统 能力资产 Docs 确认改动 交接区 PM工作区 -name '*.md' -type f | grep -Ev '历史归档|状态-archive|CHANGELOG-2026') \
    AGENTS.md 状态.md README.md 2>/dev/null \
    | grep -v "$f" | wc -l)
  echo "$count $f"
done | sort -n | head -10
```

Historical context: PROP-017 adopted a lesson from `D:\WGKJ\账号管理`. A scan found six unreferenced Markdown files; fixing them substantially improved framework health. Reference frequency was therefore added to P4c.

## P4d Bash fallback

```bash
cd "<project root>"

# Dimension 1: mtime
now=$(date +%s)
threshold=$(date -d '30 days ago' +%s)
mtime=$(stat -c %Y 状态.md)
days=$(( (now - mtime) / 86400 ))
[ "$mtime" -lt "$threshold" ] && echo "🟡 mtime is stale ($days days)" || echo "✅ mtime is $days days old"

# Dimension 2: latest date within the content
latest=$(grep -oE '[0-9]{4}-[0-9]{2}-[0-9]{2}' 状态.md | sort -ru | head -1)
echo "Latest date in the content: $latest"
```

P4d warns about stale information; it does not prove business status. `状态.md` itself says it is a snapshot, not the source of truth. Consult the latest handoff and authoritative project files as well.

## P4e historical context

Issue D arose from repeated encounters with stale Cowork mounts. Typical symptoms:

- The Windows host file changed, but Cowork Bash still reports the old byte count.
- Bash output appears precise while lagging behind Read or PS1.
- This can mislead decisions about splitting files, crossing 6500B, or whether a write succeeded.

Recorded cases with clear evidence:

- RETRO-005 card 2: cached old byte counts for `Health.jsx`.
- PM self-corrections #9 / #12: PS1 synchronization failures or different warnings.
- PM self-corrections #23 / #25: F-PREP-1 differences of -5129B / -2913B.
- PM self-corrections #26 / #32 / #36: F-BRIEFING-1 / F-DEVIATION-2 differences including -4111B / -2913B.
- PROP-018 P1: verified the CHANGELOG split by reading files back.

## Why Bash and PowerShell are not compared automatically

- PS1 runs on the Windows host and cannot directly read Cowork Bash's view.
- Staleness depends on the mount protocol, tool caches, and different synchronization strategies.
- Automatic comparison adds complex state and false positives. The MVP uses an explicit reminder and defensive workflow.

P4e is therefore a static reminder printed during every health check. It does not block work and helps PMs avoid relying on memory alone.

## P4o Bash fallback: rough estimate

> This fallback is for older environments and does not check anchors. The authoritative PowerShell P4o excludes historical archives and validates Markdown heading slugs.

```bash
cd "<project root>"

python - <<'PY'
import os, re, urllib.parse
root=os.getcwd()
scopes=['操作系统','能力资产']
bad=[]
for scope in scopes:
  for d, dirs, files in os.walk(os.path.join(root, scope)):
    dirs[:] = [x for x in dirs if x not in ['历史归档','状态-archive']]
    if '历史归档' in d or '状态-archive' in d: continue
    for name in files:
      if not name.endswith('.md') or name.startswith('CHANGELOG-'): continue
      p=os.path.join(d,name)
      text=open(p,encoding='utf-8',errors='replace').read()
      for m in re.finditer(r'!?\[[^\]]*\]\(([^)]+)\)', text):
        raw=m.group(1).strip()
        if not raw or raw.startswith('#') or re.match(r'^[a-z][a-z0-9+.-]*:', raw, re.I): continue
        target=urllib.parse.unquote(raw.split('#',1)[0]).replace('/', os.sep)
        if target and not os.path.exists(os.path.normpath(os.path.join(d,target))):
          bad.append((os.path.relpath(p,root), text.count('\n',0,m.start())+1, raw))
for row in bad[:50]: print(*row, sep=':')
raise SystemExit(1 if bad else 0)
PY
```

## Source reliability

When Bash, Read, and PS1 disagree, the current operating system uses this preference order:

1. Windows host PS1 health-check output.
2. Read or an equivalent read of the actual file.
3. Content searches such as Bash grep.
4. Bash `wc -c` or `stat` immediately after a write.

This order applies only to file synchronization and size decisions. It does not replace business tests, physical-device smoke checks, or release gates.
