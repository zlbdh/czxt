## Occasional commands for dimension 6

> Legacy Bash/GNU examples for WSL / Git Bash only. Prefer `能力资产/tools/scripts/check-handoff-zone.ps1` on Windows/Codex.

```bash
cd "<project root>"

# Pending handoff count
handoff_count=$(ls 交接区/待接手/*.md 2>/dev/null | wc -l)
echo "Pending handoff cards: $handoff_count"
[ "$handoff_count" -gt 3 ] && echo "  🟡 Backlog (at most 3 is healthy)"

# Accepted cards older than 30 days
threshold=$(date -d '30 days ago' +%s)
for f in 交接区/已接手/*.md; do
  [ -f "$f" ] || continue
  mtime=$(stat -c %Y "$f")
  [ "$mtime" -lt "$threshold" ] && echo "  🟡 $f is older than 30 days; consider archiving"
done

# Reconcile the state summary.
echo "Read the top summary in 状态.md and compare it with the newest file in 交接区/待接手/"
```

## Historical notes

The project health check began as a manual skill. High-risk checks were gradually implemented as P4 guards in `check-operating-system.ps1`. The manual documents explain why checks exist and how to assess failures; they do not duplicate every script's full implementation.

Maintenance principles:

- Keep routine entry points and the summary table in the main file.
- Keep decision rules in the individual check files.
- Put occasional commands, historical context, and report templates in appendices.
- Current results come from PS1 output.
