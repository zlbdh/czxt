# Build Scripts

**App-template reference:** this page retains examples for npm, Vite, Capacitor, and Android. It does not assert that every instance uses that stack. First read the instance's project card, real repository scripts, and CI configuration. Conflicts are resolved against the project instance source of truth.

This page does not expand the [role path allowlists](../../操作系统/01_架构/角色边界.md). Different stacks or responsibility paths require adjustment through existing governance. Actual files and command output determine current values.

## 1. npm scripts

| Command | Purpose | Actual command |
|---|---|---|
| `npm run dev` | Local Vite development with hot reload | `vite --host` |
| `npm run build` | Production build into `dist/` | `vite build` |
| `npm run test` | One-shot vitest suite | `vitest run` |
| `npm run preview` | Preview production output | `vite preview --host` |
| `npm run android:add` | First Android platform setup | `cap add android` |
| `npm run android:sync` | Build and sync Android | `npm run build && cap sync android` |
| `npm run android:open` | Open Android Studio | `cap open android` |
| `npm run android:run` | Build, sync, and run on device/emulator | `npm run build && cap sync android && cap run android` |
| `npm run android:build-apk` | Build, sync, assembleDebug; does not archive | `npm run build && cap sync android && cd android && gradlew.bat assembleDebug` |

## 2. APK packaging (issue BO / PROP-024)

### Primary Windows entry: `{{APP_REPO_DIR}}/build-apk.ps1`

Builds a debug APK and copies it to `{{APP_REPO_DIR}}/apk/{{PROJECT_NAME}}-vX.X.X-debug.apk`, the issue BQ single location.

```bash
cd {{APP_REPO_DIR}}
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-apk.ps1
```

Defenses: BO avoids `.bat` argument-parsing problems; BQ archives the APK automatically.

### Command Prompt compatibility: `{{APP_REPO_DIR}}/build-apk.bat`

Builds and assembles through a cmd-compatible entry point. Prefer `build-apk.ps1` for automatic archiving.

Defenses: BO covers `--no-pause` parsing; BH covers `.bat` CRLF.

## 3. Capacitor synchronization

Run after code changes and before installing the APK. `cap sync android` copies `dist/` to `android/app/src/main/assets/public/`.

1. `npm run build` creates `dist/`.
2. `npx cap sync android` synchronizes assets.
3. `cd android && gradlew.bat assembleDebug` builds the APK.
4. Copy it to the historical archive at `{{APP_REPO_DIR}}/apk/`.

## 6. Build-related Git configuration (issues BG / BH)

### `{{APP_REPO_DIR}}/.gitattributes`

```gitattributes
*.bat text eol=crlf      # Permanent issue BH safeguard.
*.ps1 text eol=crlf      # Same policy.
*.sh text eol=lf         # Preserve LF for POSIX scripts.
```

### Mandatory file-based commit messages

Historical issue BG: PowerShell message handling could introduce a BOM. Write `{{APP_REPO_DIR}}/commit-msg.tmp` as UTF-8 without BOM and use `git commit -F {{APP_REPO_DIR}}/commit-msg.tmp`.

The historical record reports six or more successful defenses. See the [commit encoding rule](../rules/git-commit-编码规范.md), including its permission gates.

## 9. APK paths (issue BQ v2, May 21, 2026)

All APKs reside in **`{{APP_REPO_DIR}}/apk/`**, the same ignored path for remote and zlbdh's local builds.

Historical example: `{{PROJECT_NAME}}-v3.5.8-debug.apk`. The latest version follows `{{APP_REPO_DIR}}/package.json` and `状态.md`.

Naming:

- `{{PROJECT_NAME}}-v{major.minor.patch}-debug.apk`: standard debug build.
- `{{PROJECT_NAME}}-v{major.minor.patch}-release.apk`: signed release for phase A public distribution.

Installation: transfer the APK to the phone, open it in the file manager, permit installation from that source on first use, and install. The same `{{APP_ID}}` allows an in-place upgrade. Export a JSON backup in the app before upgrading.

Historical BQ v2 decision approved by zlbdh on May 21, 2026: remove the top-level `apk/` location. Historical development APKs can be rebuilt using `git checkout vX.X.X && build-apk.bat`; version references are in the [timeline](../../操作系统/04_台账/版本时间线.md). The single artifact location is `{{APP_REPO_DIR}}/apk/`.
