## Maintenance rules

- Before adding a project, copy `项目配置/_模板.project.json` into the local project directory or `项目区/本地实例/<project>/`, then update this table as needed.
- Concrete project cards are excluded from template commits by default. Public examples require approval and removal of sensitive information before they are committed.
- Actual project code belongs in `项目区/本地实例/` or its own project root, and is not committed directly to the template repository.
- If the project already has an independent repository, record only its path and purpose here.
